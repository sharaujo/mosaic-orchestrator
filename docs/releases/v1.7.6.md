# mosAIco v1.7.6

mosAIco v1.7.6 is the first public Windows x64 release. It brings the persistent workspace for coding agents and terminals to downloadable NSIS (`.exe`) and MSI (`.msi`) installers.

## Highlights

- Offline speech recognition now uses Sherpa ONNX 2.0.1 while retaining existing models.
- Startup stops with an error if orchestrator storage cannot be prepared, and completed delegated work appears only after its final state has been saved.
- Timed-out isolated workers on Windows release their process trees before worktree cleanup.
- Plugin discovery uses the project's canonical catalogue. Agent and editor controls use neutral icons, and the remote companion uses text badges.
- Windows installers include third-party notices, license texts, and corresponding source. The release workflow verifies both installer payloads and their SHA-256 hashes before publication.

## Install or upgrade

Download the Windows x64 NSIS or MSI installer from the official [GitHub Releases](https://github.com/sharaujo/mosaic-orchestrator/releases) page. Close mosAIco before upgrading, and keep a backup of your local workspace data. The installers are currently unsigned, so Windows may display a SmartScreen warning; review the warning and file details before deciding whether to proceed.

Linux remains available from source and in CI, but no Linux binary is included in this release. There is no macOS installer or automatic updater.

For the complete change history, see the [changelog](../CHANGELOG.md).
