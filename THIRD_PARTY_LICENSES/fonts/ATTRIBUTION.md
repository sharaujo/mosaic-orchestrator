# CaskaydiaCove and Nerd Fonts attribution

The four CaskaydiaCove Nerd Font Mono TTFs are used unchanged from the official
Nerd Fonts 3.5.0 CascadiaCode archive, based on Cascadia Code 2407.24. Microsoft
owns the base-font copyright; Cascadia Code is a reserved font name under OFL.
Nerd Fonts supplied the renamed CaskaydiaCove family and describes its base-font
rehinting/preprocessing in `CascadiaCode-README.md`.

Nerd Fonts combined the following glyph sources with the font, remapping and
rescaling glyphs as required by the patcher and the Mono variant. mosAIco did not
alter the four supplied font files. CC-BY attribution includes this indication
of upstream adaptation. The full CC-BY 4.0 text is in `CC-BY-4.0.txt`.
